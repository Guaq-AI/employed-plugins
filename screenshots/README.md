# Screenshots

Store listings (Claude directory, ChatGPT plugin directory, Cursor, Kiro, Microsoft Partner Center, MiniMax) ask for real screenshots of the connector in use. Capture these from a signed-in session and save them here as PNG (1600 x 1000 or larger, light or dark, no personal data on screen). Reference them from `assets/` only after they exist; no manifest points at a missing file.

| File | Prompt to run | What it must show |
|---|---|---|
| `01-search.png` | "Find entry-level backend engineer jobs in India." | A results table or the results widget with title, company, location, work mode and apply links, and the filters used |
| `02-employer.png` | "Is Stripe hiring, and for what?" | The employer profile (role mix, locations, posting trend) followed by a few open roles |
| `03-resume-shortlist.png` | A short fake resume pasted, then "What should I apply to?" | The extracted profile bullets and a ranked shortlist with reasons and gaps |
| `04-market-brief.png` | "Brief me on Rust engineer demand in Bengaluru." | Headline number, a small table, and the limits section |
| `05-visa-honesty.png` | "Which UK software roles likely sponsor a visa?" | Results where sponsorship is described as "likely", not confirmed |

Use a throwaway account and sample data. Crop out browser chrome and any email address.
